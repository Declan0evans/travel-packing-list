# Travel Packing List

A checklist application for organizing travel essentials.

## Features

- Add packing items
- Mark packed items
- Track packing progress

## How to Use

Create a packing list and check off prepared items.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Add two items to the packing list.
- [ ] Mark one packed and verify the progress indicator.
- [ ] Delete an item and confirm the totals update.
